ВЕРСИЯ: PATCH v1.2 (ИСПРАВЛЕНИЕ QPen, ОТКАТ ДЕРЕВА И КАТАЛОГ ЖЕСТОВ)

1. Срочный багфикс: устранение NameError в карточке буквы
--------------------------------------------------------------------------------
- Файл: rsl_trainer/ui/screens/letter_card_view.py
- Проблема: При переходе в карточку буквы и вызове paintEvent виджета HandSkeletonPreview
  происходил сбой: «NameError: name 'QPen' is not defined».
- Решение:
  * В заголовок файла добавлены недостающие классы QtGui:
    from PyQt6.QtGui import QBrush, QColor, QFont, QPainter, QPen
  * Проведен аудит всех файлов в папке rsl_trainer/ui/screens/:
    все модули (gesture_card_view, exam_camera, sentence_levels, test_config и др.)
    содержат полные корректные импорты графических примитивов.
  * В тест test_gui_transitions.py добавлен вызов repaint() скелета карточки буквы
    для автоматического контроля отсутствия регрессий рендеринга.

2. Откат и сохранение раздела «Предложения / Уровни» (Duolingo Tree)
--------------------------------------------------------------------------------
- Файл: rsl_trainer/ui/screens/sentence_levels.py
- Решение:
  * Раздел возвращен к чистому исходному виду пошагового прохождения дерева уровней
    в стиле Duolingo (Уровень 1 ➔ Уровень 2 ➔ Уровень 3...);
  * Убран громоздкий свободный конструктор тегов-пилюль, перегружавший экран;
  * Сохранен интерактивный пошаговый тренажер заданной фразы уровня (Guided Composition):
    последовательная валидация жестов в окне захвата камеры, звуковая обратная связь,
    начисление +50 XP и фиксация прогресса в базе данных SQLite.

3. Редизайн и категоризация «Списка динамических жестов» (Word / Gesture Catalog)
--------------------------------------------------------------------------------
- Файлы:
  * rsl_trainer/data/gesture_categories.json (новый маппинг категорий)
  * rsl_trainer/ui/screens/word_catalog.py (полный редизайн каталога)
  * rsl_trainer/ui/screens/gesture_catalog.py (модуль-псевдоним для совместимости)
  * rsl_trainer/ui/main_window.py (регистрация псевдонима gesture_catalog)
  * rsl_trainer/ui/screens/__init__.py (экспорт GestureCatalogScreen)

- Реализованные возможности:
  3.1. Тематические фильтры (Горизонтальные Pill Tabs):
       Верхняя панель переключения категорий с подсчетом количества жестов:
       - [ 🌐 Все (966) ]
       - [ ⭐ Топ-50 базовых (50) ]
       - [ 🤝 Знакомство и вежливость (12) ]
       - [ 👨‍👩‍👦 Семья и люди (19) ]
       - [ 🏠 Дом и быт (17) ]
       - [ 🍎 Еда и напитки (18) ]
       - [ 🚗 Город и транспорт (11) ]
       - [ ⏰ Время и числа (70) ]
       - [ ⚡ Действия / Глаголы (45) ]
       Каждая категория содержит строго проверенные классы из словаря модели (label2id.json).

  3.2. Быстрый поиск «на лету» (Live Search):
       Поле QLineEdit с иконкой лупы, кнопкой быстрой очистки (clearButtonEnabled)
       и плейсхолдером: «🔍 Поиск жеста... (например, 'дом', 'друг')».
       Фильтрация карточек происходит мгновенно при вводе каждого символа (textChanged).

  3.3. Буквенный рубрикатор (А-Я):
       Компактная горизонтальная лента букв с кнопкой «ВСЕ» и буквами русского алфавита.
       Клик по букве фильтрует жесты на выбранную букву, неактивные буквы автоматически
       дизэйблятся при отсутствии слов.

  3.4. Сетка карточек (Grid Cards Layout):
       Вместо сухого системного списка реализована технологичная сетка карточек:
       - Фиксированный размер карточки (высота 115 px, мин. ширина 220 px);
       - Цветной бейдж категории (например, «Базовый», «Еда», «Семья», «Глагол»);
       - Индикатор наличия эталонного 3D-скелета («★ 3D»);
       - Крупное и четкое название жеста (15 px, bold);
       - Индикатор статуса освоения из SQLite:
           * «✓ Освоен (XX%)» (изумрудный тон)
           * «⏳ В процессе (XX%)» (янтарный тон)
           * «○ Не начат» (серый тон)
       - Клик по любой области карточки открывает gesture_card_view для демонстрации и тренировки.

  3.5. Оптимизация производительности:
       Для мгновенной отрисовки без подвисаний UI список выводится порциями по 100 карточек
       с кнопкой «Загрузить ещё...». При выборе конкретных категорий (11–70 слов) все слова
       отображаются мгновенно (время отклика < 15 мс).
