# CV-project-RSL: Распознавание Русского Жестового Языка (РЖЯ)

Система распознавания изолированных жестов Русского Жестового Языка на основе гибридного извлечения ключевых точек (YOLOv8 Pose + Google MediaPipe Hands) и иерархической рекуррентной нейросети.

Модель обучена на **999 классах** жестов (датасет *Slovo*) с разделением выборки по дикторам (`user_id`).

---

## 🏗 Архитектура решения

### 1. Извлечение ключевых точек (Feature Extraction)
Из каждого видео равномерно сэмплируется 16 кадров. На каждом кадре извлекаются 118 геометрических признаков:
* **Тело (YOLOv8-Pose)**: 17 ключевых точек скелета человека ($17 \times 2 = 34$ координаты).
* **Левая кисть (MediaPipe Tasks HandLandmarker)**: 21 точка пальцев ($21 \times 2 = 42$ координаты).
* **Правая кисть (MediaPipe Tasks HandLandmarker)**: 21 точка пальцев ($21 \times 2 = 42$ координаты).
* **Итоговая размерность сэмпла**: `(16, 118)`.

### 2. Иерархическая предобработка и нормализация
* **Тело**: координаты центрируются и масштабируются по ширине плечевого пояса (дистанция между точками 5 и 6).
* **Кисти**: координаты каждой руки центрируются по запястью и масштабируются по длине ладони (расстояние от запястья до основания среднего пальца).
* **Маски присутствия**: бинарные маски `(16, 2)`, сигнализирующие о видимости левой и правой руки в кадре (устойчивость к окклюзиям и временной потере детекции).

### 3. Нейросетевая модель (`HierarchicalGestureModel`)
* **Геометрические энкодеры**: отдельные линейные проекции с `LayerNorm`, `ReLU` и `Dropout(0.2)` для тела (34 $\to$ 64), левой руки (42 $\to$ 64) и правой руки (42 $\to$ 64).
* **Early Fusion**: слияние признаков и масок видимости (размерность 194 $\to$ 128).
* **Временной энкодер**: 2-слойный двунаправленный GRU (`hidden_size=128`, `dropout=0.3`, выход $16 \times 256$).
* **Temporal Pooling**: конкатенация Mean Pooling и Max Pooling по времени (вектор размерности 512).
* **Классификатор**: полносвязный блок с `BatchNorm1d`, `Dropout(0.4)` и выходом на 999 классов.

## 🚀 Быстрый старт

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Загрузка модели в коде
```python
import json
import torch
from train import HierarchicalGestureModel

# 1. Загрузка классов
with open("label2id.json", "r", encoding="utf-8") as f:
    label2id = json.load(f)

# 2. Инициализация и загрузка весов
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = HierarchicalGestureModel(num_classes=len(label2id))
model.load_state_dict(torch.load("best_hierarchical_model.pth", map_location=device))
model.to(device)
model.eval()

print(f"Модель успешно загружена! Количество классов: {len(label2id)}")
```
