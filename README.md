# CV-project-RSL: Распознавание Русского Жестового Языка (РЖЯ)

Система распознавания изолированных жестов Русского Жестового Языка на основе гибридного извлечения ключевых точек (YOLOv8 Pose + Google MediaPipe Hands) и иерархической рекуррентной нейросети.

Модель обучена на **999 классах** жестов (датасет *Slovo*) с разделением выборки по дикторам (`user_id`).

---

## 🏗 Архитектура решения

### 1. Извлечение ключевых точек (Feature Extraction)
Из каждого видео равномерно сэмплируется 16 кадров. На каждом кадре извлекаются 118 геометрических признаков:
* **Тело (YOLOv8-Pose)**: 17 ключевых точек скелета человека ($17 \times 2 = 34$ координаты).
* **Левая кисть (MediaPipe Tasks HandLandmarker)**: 21 точка пальцев ($21 \times 2 = 42$ координаты).
* **Правая кисть (MediaPipe Tasks HandLandmarker)**: 21 точка пальцев ($21 \times 2 = 42$ координаты).
* **Итоговая размерность сэмпла**: `(16, 118)`.

### 2. Иерархическая предобработка и нормализация
* **Тело**: координаты центрируются и масштабируются по ширине плечевого пояса (дистанция между точками 5 и 6).
* **Кисти**: координаты каждой руки центрируются по запястью и масштабируются по длине ладони (расстояние от запястья до основания среднего пальца).
* **Маски присутствия**: бинарные маски `(16, 2)`, сигнализирующие о видимости левой и правой руки в кадре (устойчивость к окклюзиям и временной потере детекции).

### 3. Нейросетевая модель (`HierarchicalGestureModel`)
* **Геометрические энкодеры**: отдельные линейные проекции с `LayerNorm`, `ReLU` и `Dropout(0.2)` для тела (34 $\to$ 64), левой руки (42 $\to$ 64) и правой руки (42 $\to$ 64).
* **Early Fusion**: слияние признаков и масок видимости (размерность 194 $\to$ 128).
* **Временной энкодер**: 2-слойный двунаправленный GRU (`hidden_size=128`, `dropout=0.3`, выход $16 \times 256$).
* **Temporal Pooling**: конкатенация Mean Pooling и Max Pooling по времени (вектор размерности 512).
* **Классификатор**: полносвязный блок с `BatchNorm1d`, `Dropout(0.4)` и выходом на 999 классов.

## 🚀 Быстрый старт

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Загрузка модели в коде
```python
import json
import torch
from train import HierarchicalGestureModel

# 1. Загрузка классов
with open("label2id.json", "r", encoding="utf-8") as f:
    label2id = json.load(f)

# 2. Инициализация и загрузка весов
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = HierarchicalGestureModel(num_classes=len(label2id))
model.load_state_dict(torch.load("best_hierarchical_model.pth", map_location=device))
model.to(device)
model.eval()

print(f"Модель успешно загружена! Количество классов: {len(label2id)}")
```

## 🖥 Десктоп-приложение «Тренажер РЖЯ» (Beta MVP)

Интерактивный мультимедийный тренажер жестового языка, созданный на **PyQt6** с аппаратным ускорением рендеринга и полной изоляцией компьютерного зрения в фоновом потоке `QThread`.

### ⚡ Оптимизация под стандартные CPU (30–60 FPS)
* **Разделение режимов трекинга (Dual-Mode Pipeline)**:
  * В режиме дактиля (алфавит, карточки букв, экзамен) тяжелая детекция YOLO полностью отключается, инференс выполняет только MediaPipe Hands (~27 мс / 36+ FPS на CPU).
  * В режиме динамических жестов входные кадры для YOLOv8-pose сжимаются до 320x240, ускоряя детекцию в 3–4 раза.
* **Последний кадр**: поток камеры хранит один актуальный пакет; интерфейс забирает его по таймеру. Устаревшие пакеты заменяются, а классификация жеста выполняется в отдельном потоке.
* **Силуэт под камерой**: в динамической тренировке и предложениях показаны движение рук относительно тела и увеличенные кисти. Для всей траектории применяется единый масштаб; для дактиля доступна подсветка отклонений на камере.
* **Target-Constrained Verifier**: валидация $\text{Class}_{target} \in \text{Top-3} \land P \ge 0.30$.
* **Ошибки камеры**: при невозможности открыть устройство или потере кадров показывается ошибка с кнопкой переподключения. Синтетические кадры вместо камеры не используются.

### Обучение динамическому жесту

После отсчета 3–2–1 выполните движение целиком за время записи (по умолчанию 2 секунды). В настройках можно выбрать от 1 до 8 секунд. Из всей записи по времени выбираются 16 фаз для модели; пустая или прерванная запись не оценивается.

Для изучения включена скорость **0,5×**. Доступны 0,25×, 0,5×, 0,75× и 1×, пауза, переход к соседним фазам и ползунок. Между исходными фазами показ плавно интерполируется; перед повтором есть остановка. Длительность изучения не меняет время записи попытки. Во время самой записи образец проходит движение один раз за отведенное время, затем вновь доступны настройки просмотра.

Режим **«Объём»** строит ладонь и округлые фаланги по суставам из имеющихся записей; **«Контур»** показывает плоскую схему. В карточках букв оболочку можно вращать мышью и сбросить двойным щелчком. Сохранённые `.npy` содержат только X и Y: оболочка имеет объём, но глубина центров суставов не восстановлена. Поворот такой оболочки — приближённая визуализация. Построитель поддерживает также точки X/Y/Z для будущих примеров с сохранённой глубиной.

Для букв выбирается рабочая, поднятая рука и устойчивая конфигурация из доступных примеров класса. Посторонние изображения и вручную придуманные позы не подставляются вместо данных модели.

Силуэт использует исходные пиксельные координаты из `rsl_trainer/assets/skeletons/`. Если готового эталона нет, приложение ищет пример соответствующего класса в `hybrid_tensors/train/`. Эта папка исключена из Git: на другом компьютере без неё демонстрация доступна только для приложенных эталонов. Для остальных жестов отображается сообщение об отсутствии эталона.

### 🧪 Запуск автоматических тестов QA
```bash
python -m pytest tests/
```

Тесты камеры используют подставное устройство и проверяют настоящий поток захвата, освобождение камеры, переподключение и отбрасывание устаревших кадров. Тесты экранов работают с временной базой, не меняют пользовательский прогресс и не включают физическую камеру. Отдельно проверяются загрузка модели, прямой проход, удержание букв, запись полного жеста и отрисовка эталонов. Снимки экранов для проверки расположения элементов сохраняются в `.pytest_cache/previews/`.
