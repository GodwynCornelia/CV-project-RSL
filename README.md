Интеллектуальная программная система непрерывного перевода потоковой жестовой речи в связный естественный текст на основе **кинематической сегментации**, **гибридного скелетного трекинга (YOLOv8 + MediaPipe)**, **иерархической рекуррентной нейросети** и **семантического декодера на базе LLM Qwen**.

---

## 📌 Проблема и мотивация проекта

Синхронный машинный перевод непрерывной жестовой речи (Continuous Sign Language Translation — CSLT) традиционно считается одной из сложнейших задач Computer Vision и NLP:
1. **Дефицит размеченных датасетов непрерывной речи:** сквозное (End-to-End) обучение требует сотен часов видео непрерывного диалога с пословной разметкой, которых для РЖЯ практически не существует.
2. **Эффект коартикуляции:** в слитном потоке жестов отсутствуют паузы; окончание одного жеста плавно перетекает в подготовку следующего.
3. **Топологическая грамматика РЖЯ:** грамматика жестового языка принципиально отличается от звучащего русского языка — в ней используется пространственный синтаксис «Тема — Рема», отсутствуют предлоги, союзы и падежные окончания. Прямая конкатенация распознанных глосс не дает читаемого текста.

> **Решение проекта:** Разделение задачи на кинематическое выделение границ жестов (Action Spotting), вероятностную классификацию (Candidate Lattice) и семантическое восстановление грамматики внешней языковой моделью (LLM Contextual Decoder).

## 💡 Патентная формула и техническая новизна

**Название изобретения:**  
*«Способ и система машинного перевода непрерывной жестовой речи в связный естественный текст на основе кинематической сегментации, гибридного извлечения скелетных признаков и вероятностно-семантического декодирования»*.

```
[ Веб-камера / Видеопоток ]
            │
            ▼
[ 1. Гибридный трекинг (YOLOv8 + MediaPipe) ] ──> 118 координат/кадр
            │
            ▼
[ 2. Кинематический споттер (EMA Скорость / Ускорение) ] ──> Триггер границы жеста (16 кадров)
            │
            ▼
[ 3. Иерархическая нейросеть (HierarchicalGestureModel) ]
            │
            ▼
[ 4. Решетка гипотез (Top-5 Lattice Graph DAG + Beam Search) ]
            │
            ▼
[ 5. Семантический LLM-декодер (Qwen-2.5) ] ──> Литературный русский текст
            │
            ▼
[ 6. Патентный GUI стенд (PyQt6 + Осциллограф + TTS) ]
```

### Ключевые патентные узлы:
1. **Кинематический детектор границ жестов (Action Spotting):**
   * Вычисление мгновенных дифференциальных скоростей запястий: $v_t = \max(v_{left}, v_{right})$.
   * Сглаживание через экспоненциальное скользящее среднее (EMA, $\alpha = 0.3$): $v_t^{ema} = 0.3 v_t + 0.7 v_{t-1}^{ema}$.
   * Детекция фаз жеста: `IDLE` $\to$ `PREPARATION` $\to$ `STROKE` $\to$ `RETRACTION`.
   * Фиксация границы жеста по падению ускорения ($a_t = v_t^{ema} - v_{t-1}^{ema} \le \text{Threshold}_{stop}$) либо фазовому покою, с формированием тензора `(16, 118)`.
2. **Взвешенный граф гипотез (Candidate Lattice DAG & Beam Search):**
   * Вместо ненадежного жесткого выбора Top-1 система формирует ориентированный ациклический граф (DAG) из Top-5 гипотез на каждом шаге с весами $-\log P(\text{gloss})$.
   * Алгоритм Beam Search со штрафом за анти-статтеринг отбирает наиболее вероятные глобальные пути до передачи в LLM, минимизируя вычислительную нагрузку.
3. **Семантический контекстный декодер (Qwen LLM):**
   * Специализированный модуль промпт-инжиниринга, трансформирующий цепочку изолированных начальных форм (глосс) в грамматически согласованное предложение на литературном русском языке с восстановлением падежей, чисел, предлогов и времен.

## 🏗 Архитектура нейросети (`HierarchicalGestureModel`)

Модель классификации обучена на **999 классах** жестов датасета *Slovo*:
* **Входной вектор кадра (118 признаков):**
  * Тело: 17 ключевых точек скелета человека (YOLOv8-Pose) $\to$ 34 координаты.
  * Кисти: по 21 точке на каждую кисть (Google MediaPipe Tasks) $\to$ 84 координаты.
* **Локальная анатомическая нормализация:**
  * Тело нормализуется относительно центра и ширины плечевого пояса.
  * Кисти центрируются по запястью и масштабируются по размеру ладони (пястно-фаланговый сустав).
  * Формируются маски видимости `(16, 2)` для устойчивости к окклюзиям.
* **Слои модели:**
  * Пространственные энкодеры тела (34 $\to$ 64) и кистей (42 $\to$ 64) с `LayerNorm` и `Dropout(0.2)`.
  * Early Fusion признаков (194 $\to$ 128).
  * 2-слойный двунаправленный рекуррентный блок **BiGRU** (`hidden_size=128`, `dropout=0.3`, выход $16 \times 256$).
  * Комбинированный **Temporal Pooling: Mean + Max Pooling** (вектор размерности 512).
  * MLP-классификатор с `BatchNorm1d` и выходом на 999 классов.
* **Вес чекпоинта:** всего **3.68 МБ** ([best_hierarchical_model.pth](file:///i:/Пет%20проект/CV-project-RSL/best_hierarchical_model.pth)), что обеспечивает инференс в реальном времени даже на CPU.

## 🖥 Интерфейс оператора (PyQt6 Dashboard)

Специально для патентной экспертизы и демонстрации разработан графический стенд:
* **Экранный видеохолст:** отображение потока с веб-камеры с наложением неонового скелета (тело — неоновый синий `#38bdf8`, пальцы — зеленый `#4ade80`).
* **Осциллограф кинематики:** динамический график скорости рук $v_t^{ema}$ в реальном времени с красной линией порога отсечки и визуальным индикатором фазы.
* **Лента сегментов:** интерактивные карточки распознанных слов с бейджами вероятностей Top-5.
* **Студия перевода:** защищенное окно вывода текста (Read-Only) и асинхронный движок синтеза речи (TTS).
* **Встроенный демо-режим:** синтез тестовой жестовой фразы без необходимости включения камеры.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
git clone https://github.com/GodwynCornelia/CV-project-RSL.git
cd CV-project-RSL
git checkout patent
pip install -r requirements.txt
```

### 2. Запуск графического интерфейса
```bash
python run_app.py
```

### 3. Инструкция по тестированию с веб-камеры ноутбука
1. Нажмите кнопку **«📹 Камера»** в нижней панели GUI.
2. Сядьте на расстоянии **1–1.5 метра** от ноутбука так, чтобы в кадре четко помещались голова, плечи и обе руки (YOLO ориентируется на плечевой пояс для нормализации, а MediaPipe — на кисти).
3. Обеспечьте нормальное освещение (избегайте яркого света позади себя).
4. Выполняйте жесты плавно, делая небольшую естественную паузу (0.3–0.5 сек) между словами:
   * На осциллографе вы увидите, как кривая скорости кистей взлетает во время активной фазы (`STROKE`), а в момент остановки падает ниже красной пунктирной линии порога (`TRIGGER`).
   * В правой ленте мгновенно появится карточка распознанного слова с вероятностями Top-5.
5. После выполнения цепочки жестов нажмите **«⚡ Перевести фразу»** для запуска семантического синтеза Qwen LLM, а затем **«🔊 Озвучить»** для голосового воспроизведения.

### 4. Запуск автоматических тестов
```bash
# Модульные тесты кинематики, графа и декодера
python tests/test_kinematic_spotter.py
python tests/test_lattice.py
python tests/test_semantic_decoder.py

# Сквозной интеграционный тест фразы из реальных тензоров
python tests/test_synthetic_e2e.py
```
